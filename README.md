## Development

Use Node.js 22.12 or newer. Install dependencies with `npm ci`. `npm start` serves the app at http://localhost:3000. `npm test` runs the test suite; `npm run build` writes the production bundle to `build/`. `npm run preview` serves that bundle. Vite replaces the unmaintained Create React App toolchain.
